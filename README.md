# lint-agent

> AI linting — enforces your team'\''s style, naming, and architecture rules.

## What it does

Learns from your existing codebase what 'good' looks like, then flags deviations in new PRs. Goes beyond syntax — catches wrong abstraction levels, wrong layer calls, inconsistent naming.

## Quickstart

```bash
pip install lint-agent-ai
```

## Usage

```bash
lint-agent train src/ && lint-agent check feature-branch/
```
